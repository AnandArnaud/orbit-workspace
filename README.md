# orbit-workspace

Orbit is a minimal SaaS project workspace — sign up, log in, create and complete tasks, invite teammates, upgrade.

**Stack:** Next.js 15 (App Router, TypeScript)

It is intentionally small. The user-action handlers log to the console.

## User actions worth tracking

sign up · log in · create task · complete task · invite · upgrade

## Running it

```bash
npm install
npm run dev   # http://localhost:3000
```
